Executive Summary

This report maps the open-source GitHub landscape across five categories critical to GranMonte's US wine distribution launch: wine inventory management, restaurant ordering/POS systems, alcohol regulatory compliance, Thai restaurant POS, and distribution logistics. We analyzed 20+ repositories using GitHub API data, README inspection, and web research.

Key finding: The wine distribution space on GitHub is fragmented — no single repo covers the full importer-to-restaurant pipeline. However, several high-quality building blocks exist that can be composed into a custom stack for GranMonte. The strongest candidates are Kessly (wine distribution SCM), Cellarion (modern MERN wine management with AI), Fleetbase (1.8K★ logistics OS), and Spree Commerce (14K★ B2B e-commerce). For compliance, the landscape is almost entirely proprietary — the BC Government's CARLA liquor licensing system is the only substantial open-source regulatory codebase found.

Bottom line for Up: Rather than adopting any single repo, the optimal strategy is to fork/adapt 2–3 targeted tools (Kessly for distribution ops, Fleetbase for delivery tracking) and build a thin integration layer — which is exactly what a JARVIS agent could orchestrate.

Alcohol Import Compliance & Regulatory

Open-source tools for alcohol regulatory compliance — TTB reporting, COLA label approvals, state licensing, and excise tax calculations. This is the thinnest category on GitHub — the compliance space is dominated by proprietary SaaS (Sovos ShipCompliant, 365WineTrade, Joy of Wine).

bcgov/jag-lcrb-carla-public
C# / .NET ⭐ 13 ● Active (Apr 2026) Apache-2.0

BC Liquor and Cannabis Regulation Branch — CARLA Licensing Application. Built by the British Columbia government for managing liquor and cannabis licensing applications. Includes federal reporting module, license lifecycle management, compliance tracking, and multi-tenant architecture. 43 contributors, 77M+ lines of C#. The most comprehensive open-source alcohol regulatory system on GitHub.

⭐ 13 stars 🍴 49 forks 👥 43 contributors 📅 Created Mar 2018 📦 77M+ lines C#
GranMonte Relevance — HIGH (as reference architecture). While this is Canadian (BC), the regulatory concepts are transferable: license application workflows, compliance status tracking, federal reporting pipelines, and multi-entity management. GranMonte needs to track its TTB permit status, COLA label approvals, and FL JDBW distributor license — CARLA's data model shows how a government-scale system handles these workflows. Not forkable directly, but invaluable for designing GranMonte's compliance tracking module.

UC Davis Wine Ontology — RDF data model for wines and the wine industry. Defines structured data relationships for wine labeling, TTB regulations, brand names, varietals, regions, and production methods. References TTB labeling rules directly in the ontology. Academic project from UC Davis Library.

🏫 UC Davis Library 📅 Academic project 📄 OWL/RDF format 19 commits
GranMonte Relevance — MODERATE (data model). This is useful for auto-validating GranMonte's COLA label submissions before filing with TTB. The structured wine vocabulary (appellations, varietals, vintages) is a solid foundation for a product database.

⚠ Gap Analysis: Compliance Software

No open-source tools exist for US alcohol import compliance. The following critical functions have zero GitHub coverage:

  • TTB federal reporting — Monthly operational reports required by TTB for importers
  • COLA label submission — Certificate of Label Approval workflow with TTB
  • State excise tax calculation — FL wine excise is $2.25/gallon + various surcharges
  • Three-tier compliance tracking — Ensuring importer→distributor→retailer chain is legal
  • FL JDBW license management — The specific license GranMonte needs
Implication for GranMonte: Compliance automation is a build-from-scratch effort. This is actually an opportunity — if mhoooo builds a JARVIS compliance module that handles TTB reporting + state excise + COLA tracking, it becomes a sellable product to other small wine importers. The proprietary alternatives (Sovos ShipCompliant, 365WineTrade) charge $500–2,000+/month.

Strategic Recommendations for GranMonte US Launch

  1. P0
    Fork Kessly as the operational backbone. It's MIT licensed, wine-distribution-specific, and covers 70% of GranMonte's day-one needs (inventory, orders, customers, invoicing). Customize: add GranMonte's pricing formulas from the AOC Wine Distributor repo, add Florida excise tax fields ($2.25/gal wine), and build a TTB monthly report generator. Estimated effort: 2–3 weeks of JARVIS-assisted development.
  2. P1
    Build a compliance module from scratch. No open-source solution exists. Use CARLA's data model as reference. Track: TTB permit status, COLA label approvals (per SKU), FL JDBW license progress, federal excise tax payments, and state reporting deadlines. This becomes a sellable asset — small wine importers would pay $100–300/mo for this. Start with a simple spreadsheet-to-dashboard approach, automate later.
  3. P2
    Extract the pricing engine from AOC Wine Distributor. The markup formula logic (FOB + duties + shipping + margin = wholesale price) is directly applicable. Adapt for GranMonte: GranMonte Khao Yai FOB (from price list) → TTB duty → ocean freight → FL excise → distributor margin → restaurant wholesale price. Auto-generate price sheets for restaurant buyers.
  4. P3
    Deploy Fleetbase when delivery volume justifies it. Initially, Up will likely deliver wine personally or use a local carrier. Once GranMonte is supplying 10+ restaurants, Fleetbase's route optimization and delivery tracking become valuable. The driver app lets delivery staff capture proof-of-delivery photos — important for compliance auditing.
  5. P4
    Use Cellarion's AI pipeline for competitive intelligence. Adapt the Claude Vision label scanning to catalog competitor wines at Thai restaurants during sales visits. Build a "what wines are Thai restaurants in Florida currently carrying?" database. This intelligence drives the sales pitch: "You're carrying [X wine] at $Y — GranMonte offers authentic Thai terroir wine at $Z."
  6. P5
    Consider the LanAim Thai POS as a Trojan horse. Offer Thai restaurants a free, Thai-language POS upgrade with a built-in GranMonte wine ordering module. This creates stickiness — once the POS is installed, reordering GranMonte wine is one tap. High-effort, high-reward play for after initial traction is proven.
